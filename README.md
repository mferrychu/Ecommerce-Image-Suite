# Ecommerce Image Suite

面向 AI 编程助手的电商商品图制作 Skill：以产品实拍图和真实商品资料为依据，完成买家顾虑分析、逐图策划、文案、图像制作与质量检查。

默认交付 **3 张主图 + 5 张详情图**，单次最多 **10 张**。支持仅策划与提示词、独立详情图及拼接长页。

## 安装

将此仓库克隆到本地，然后把整个 `ecommerce-image-suite` 文件夹放入助手的技能目录。文件夹内必须保留 `SKILL.md` 与 `references/production.md` 的相对位置。

以 Codex 用户技能目录为例：

```bash
git clone https://github.com/mferrychu/Ecommerce-Image-Suite.git ecommerce-image-suite
mkdir -p ~/.codex/skills
cp -R ecommerce-image-suite ~/.codex/skills/
```

如果目标目录已有同名技能，请先备份再更新。安装后在新会话中检查技能是否可用。

此仓库提供 Markdown 工作流，无需安装项目依赖。实际生成图片需要宿主助手具备图像生成或编辑能力；核实平台要求时需要联网能力。仅做策划时可不调用图像工具。

## 开始使用

附上产品实拍图，并提供商品名称、准确 SKU、颜色、包装和随附物、真实参数、目标平台与市场、图片语言，以及详情图交付形式。

```text
用 $ecommerce-image-suite 给这款商品做电商图。
产品实拍图见附件。
商品名／型号：____
本次销售款、颜色、包装及随附物：____
已确认的参数、材质和功能：____
服务／资质及证明：____
目标平台／市场：____
图片语言：____
主图 3 张，详情图 5 张；详情图分别交付。
品牌素材、风格参考和禁用内容：____
```

只需要策划时，补充“先做策划和提示词，暂不生图”。缺失信息写“未知”，由助手核对，不用同类商品参数填补。

## 工作流程

1. 核对照片、销售款、商品资料与输出要求，记录事实和待确认项。
2. 按买家决策拆解主要顾虑，为每张图安排一个核心问题。
3. 编写逐图文案与提示词，统一色彩、字体和信息层级。
4. 以实拍外观为锚生成或编辑图片。
5. 检查产品一致性、文案与单位、可读性、平台要求和套图一致性。
6. 交付最终图片、逐图方案与提示词、事实依据、示意范围和待确认项。

## 使用边界

- 不编造参数、配件、功效、认证、销量、库存或服务承诺。
- 单张模糊图片无法可靠还原产品时，先确认限定范围、仅做策划或等待补图。
- AI 场景属于示意，不能作为真实工厂、认证或性能证明。
- 发布前仍需对照实物、最终销售资料和目标平台要求复核。
