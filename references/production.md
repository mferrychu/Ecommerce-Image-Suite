# 制作规范

本文件供执行图片生产与验收时读取；入口规则见 `../SKILL.md`。

## 资料核对表

| 项目 | 开工处理 |
| --- | --- |
| 实物图片 | 至少一张；检查主体是否完整、关键结构是否清楚、有无强反光／遮挡、是否与目标 SKU 相同。多图、背标和细节图能显著降低重绘误差。 |
| 准确销售款 | 核对型号、颜色、规格、包装内容、随附物。多 SKU 时要求用户指明本次做哪一款或分别制作。 |
| 商品资料 | 保留原始表述和单位；识别“同类常见”“通常”“可能”等非本品数据，不能转成卖点。 |
| 渠道、市场、语言 | 用于确定画幅、主图文字许可、单位、文案语言与目标买家。规则不明时询问或核实，不能假称平台允许。 |
| 输出 | 张数默认 3＋5、最多 10；详情是独立图片还是拼接长页；如用户已有尺寸或文件格式要求则遵循。 |
| 品牌与证明 | 官方 Logo、商标、认证、测试报告、工厂和服务信息只在用户确认或材料可核验的范围内使用。 |

提问应只覆盖真正缺失和冲突的项目。用户已在本轮或此前明确给出的信息持续有效，不重复问。若目标平台未定，可提供“请指定平台／渠道，或明确同意通用展示方案”供用户选择；默认不替其选择。设计风格与布景可自行判断，拿不准且会影响购买表达时再问用户。

## 事实与宣称

- **图片可见：**外观、颜色、结构、包装可读文字。看不清的文字和内置部件不视为可见。
- **用户确认：**用户直接说明的参数、配件、工艺或服务。若与图片或别的资料明显冲突，列为待确认。
- **文件可核验：**产品参数表、背标、检测资料等。转录精确数字前检查单位与上下文；技术翻译保留原意，例如持续功率与峰值功率不能互换。
- **待确认／禁用：**同类产品推测、无法验证的功效、资质、销量、库存、发货时效、绝对化用语、医疗和安全保证。未确认前不进入图中文字，也不作为逼真的画面证据。

用户提供的卖点也可能是营销草稿。将其转成图片宣称前，判断是否可由实物或资料支持。“品质升级”“专业制造”等空泛词改成可见结构、真实参数或已确认服务；无法落地则舍弃，不伪造证明材料。参考图只学习信息层次、图文配合和节奏，不照抄品牌、版式、文案、水印或把参考商品特征移植到本品。

场景生成要区分“使用方法示意”与“事实证明”。例如人物使用可帮助理解操作，但不能代替实测性能；工厂、仓库、认证证书、客户评价及售后团队图若无真实素材，不应被画成该商家的实景。生成图需在交付说明中标出关键示意内容；发布前应对照实物、背标与最终销售承诺复核。

## 逐图策划

先回答买家会问什么，再决定画面。不必每款产品都覆盖同一套顺序。

| 问题类型 | 适用表达示例 | 常见误区 |
| --- | --- | --- |
| 买到什么 | 完整产品、包装、准确 SKU | 主体太小，AI 改了结构或出现多余配件 |
| 与我如何相关 | 相称的人物、空间和使用动作 | 只做摆拍或暗示未经证实的效果 |
| 具体哪里好 | 可见材质／结构特写、可核实参数 | 纯形容词、假剖面、虚构内部构造 |
| 怎么使用／安装 | 准确的步骤或场景示意 | 步骤与实物不符、遗漏重要前提 |
| 尺寸和适配 | 清晰尺寸线、单位、参照 | 猜尺寸、比例失真、把示意图当工程图 |
| 购买保障 | 真实保修、包装和售后信息 | 虚构厂房、现货、认证与物流时效 |

每张图用以下字段记录即可，不必强制表格：序号与用途、买家问题、证据、标题／辅助文案、主体和场景、构图、光线、文字区域、必须保留的产品特征、禁止编造项。一个核心问题可以包含相关的两三个支撑参数，但不要把多个不相关卖点塞到一张图。主图承担吸引与辨认，详情页逐步解释；两者要互补。

视觉策略根据品类变化。食品可以是食材、料理动作与餐桌；家电可结合操作、照明效果和结构；健身器材可组合全貌、真人比例、运动轨迹及规格；工业品可强调结构、用途和采购信息。这些只是可选方法，不是固定模板。

## 生成与质检

制作提示词需说明产品锚点、真实场景、镜头距离／角度、画幅、主光方向、色彩、文字安全区，以及禁止增减的结构或信息。复杂技术图可用实物图配准确标注；不要让图像模型凭空设计内部零件或把说明性线条做成产品功能。人物动作要自然并符合使用方式。商业情景有证明意味时需真实素材支持。

逐图验收：

1. **商品：**型号、颜色、轮廓、关键部件、包装、数量、配件与原图一致；没有多出来的灯带、屏幕、接口、按钮、徽标等。
2. **文案：**语言、错别字、单位、数字、换算、大小写正确；与事实清单对应，不夸大、不用空泛口号凑字。
3. **买家理解：**缩小到移动端尺寸后仍能看清主张；图片一眼说明其核心问题；画面与文字没有互相重复到浪费空间。
4. **套图：**字体和品牌位置有规则，色调一致；景别、构图和信息密度有变化；主图、详情页的职责清楚。
5. **交付：**只交验收过的最终图；按主图／详情页编号；附可复现的逐图提示词、使用的事实、AI 示意范围及待确认项。若平台或上架系统有文件规格要求，另核对尺寸、格式和大小。

如果一张图反复生成仍无法忠实表示结构或文字，改用实拍裁切＋可控排版、缩小该图承诺，或向用户说明无法可靠完成的部分；不把明显错误图当成成品交付。AI 图片是待实物和最终销售资料核对的视觉稿，是否可直接上架取决于相应事实、平台要求和发布方复核。
